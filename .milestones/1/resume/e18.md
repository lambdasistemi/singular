## Standing rules learned here

1. A control that survives removal of what it certifies is decoration.
2. A mutant must succeed at everything except the thing under test.
3. An empty grep, a failed lookup, and an absent field are not proof of absence.
4. **A built artifact outranks source text, and source text outranks a comment.** Four faults today
   came from inverting this — most recently a `types.ak` comment claiming a parameter the compiled
   blueprint does not have.
5. Authority is a role, not a vocabulary (`State.stake_script` was an owner hook that never said
   "owner").
6. Check the fence **after** a merge moves the base, with `merge-base`.
7. A `pull_request` run takes the **workflow from the base**, the **flake from the head**.
8. Scan whole declaration spans, never a fixed line window.
9. Do not manufacture a user decision; and **an absence in the model is not a scope waiver.**
10. Coverage is not inherited across a wire-format change; applicability changes earn no credit.
11. `HANDOFF` is not a terminal tag. Do not end a turn on an intention.
12. Every brief lists `worker-protocol`, or the seat journals prose nobody can wait on.
13. Generate or verify mechanically; never eyeball hex.
14. A repaired-only rerun is not a pre-repair RED.
15. **A global red can hide a per-obligation false credit.** The clause-deletion control exited 1
    both times and looked fine; the failure was in numbers nobody was comparing.
16. **Run controls against a frozen archive, never a live worktree.** A moving HEAD makes a control
    not-a-control; a preflight that refuses for that reason is working.
17. **Verify the target file's diff before reporting a fix.** A commit that changes a neighbouring
    file and a receipt that says "done" is the same defect as an unrun check.
18. **A child's turn ending with a result and a plan is a turn *ending*.** Control returns to the
    owner; continuation is the owner's to send. A `COMMIT`/`GATE-PASS` with named next work and no
    blocker needs owner continuation — a live devnet or an armed heartbeat is not evidence the
    worker is running. This lane stopped on "Next: …" four times before I fixed my side of it.
19. **`HEAD` is not the state — `HEAD` plus `git status` is.** A clean commit pointer over a dirty
    tree is not that commit. Checking the pointer and skipping the status is how a live-tree probe
    gets reported as a frozen-commit result (2026-09-12, alias-coverage probe).
