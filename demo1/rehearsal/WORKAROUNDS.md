# The rehearsal's workarounds

Every place a scene or a harness script does something a user following the
guide would not do carries, at that spot, a `# WORKAROUND: <what the user
hits> -> <what the script does>` comment, and a row here. The final phase of
every run checks the two directions mechanically: each comment's left text
appears verbatim in some row's symptom cell, and each row whose workaround
does not start with `no site:` has at least one comment at its site. A row
with no live site any more (a dry run of an earlier take that failed and was
fixed in the harness, or a cause the product has since removed) says
`no site:` and what was fixed or which change retired it. The desk reviews
the product rows with the operator.
