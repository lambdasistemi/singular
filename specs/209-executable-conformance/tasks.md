# Work ledger

Unchecked means outstanding, not authorized completion. Candidate checkpoints
are not acceptance stamps. Each completed task needs a candidate and receipt.
Tasks are grouped by the child ticket that owns them; a task belongs to exactly
one child and is fenced by that child's pull request.
