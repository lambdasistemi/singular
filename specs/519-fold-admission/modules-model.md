## Rules

- **model-first** (invariant): the model, its statements and its exported corpora land in pull requests 1 and 2 before any builder or validator test cites them; each pull request carries its own constitution amendment. Enforced by the order of the pull requests and by `tools/check_model.py` reconciling the constitution's translation table.
- **one-predicate-one-owner** (invariant): the window is judged by one function in each language, `foldAdmission`, and the library function is checked against the model's by the conformance unit suite at the boundary and one past it. The selection, the builder and the command line call the library function; none restates it.
- **derived-files-are-regenerated** (invariant): corpora, exports, the simulator mirror, the coverage record and the audio clips are regenerated by their commands, never edited by hand and never hand-merged at a rebase.
- **no-validator-source-edit** (invariant): `onchain/validators/**/*.ak` other than tests, `onchain/lib/**` other than the fixtures module `onchain/lib/registry_fixtures.ak`, `onchain/permanent-contract.json` and `onchain/script-identity.json` do not change; the script identity job proves the compiled hashes did not move.
- **swap-rule** (invariant): `window-closed` and the sentence that the model admits a fold the validator refuses are deleted in the same change that replaces them.
- **dependency-direction**: the command line and the conformance suite depend on the registry library; the library depends on no command-line module and no open-datum module. The check is placed in the library for that reason: the Lean driver transport exists only in the conformance package.
- **promotion**: the deadline comparison is promoted out of the command line (`FoldRules` today) into the library, the nearest stable owner the command line, the builder, the selection and the conformance suite can all use. Nothing else is promoted.
