## Accepted design

Identity is the token plus the release. There is no saved identity, join command, caller-supplied
reference hint or forever lock. Anyone can rebuild and publish checked reference scripts to outputs
they control, and spend them back. Search tries the provider before the actor wallet, reading only
missing needed roles and hashing exact candidate scripts locally. Empty provider answers establish
only provider absence. The accepted rulings of 2026-10-06 and 2026-10-07 remain authoritative:
permissionless republishing, saved-selector retirement, archive-bound page facts, shared state
carrier retirement, a closed funding interface and independently checked report action identity.

| decision | rejected alternative | reason |
|---|---|---|
| token plus release supplies identity | Carol's saved registry file | Bob must not depend on Carol's disk |
| permissionless reference outputs | permanently unspendable references | anyone can restore the convenience carriers |
| provider then wallet, no hints | a page hint fallback | the operator removed its extra failure path |
| opaque wallet funding boundary | enumerated call-graph checks | the compiler excludes a stray ordinary selector |
| tagged archive links and computed evidence | typed limits or current-main Pages | a page must identify the release it actually describes |
