# The registry page: tasks

Story, requirements and refusals are in the [spec](spec.md); slices, gate and signatures are in the
[plan](plan.md). One writer, commits per slice, each commit builds. Every check is run failing
before it is made to pass, and the failing run is kept.

## Slice 1: lineage facts

- [ ] lineage-facts-red: a replay of a known history, with repeated and re-terminated keys,
  reports the create, the folds and the distinct keys; the test fails on the base.
- [ ] replay-reports-named-keys: `Replayed` carries the keys the applied updates named.
- [ ] snapshot-carries-lineage: the snapshot reports `PublicLineage`; the fixture snapshot says
  it has none; the three replay expectations of the end-to-end suite name the keys.

## Slice 2: page value

- [ ] page-render-red: determinism, same-facts-in-both-renderings and version refusal checks fail
  on the base.
- [ ] page-value-and-renderers: `Page`, `ReleaseInfo`, `releaseLinks`, `parseVersionLabel`,
  `describeRegistry`, `renderPageText`, `renderPageJson`.

## Slice 3: describe command

- [ ] describe-parse-red: write settings refused by name; a missing token; `--json` accepted.
- [ ] describe-command: the argument record, the subcommand, the usage lines, the dispatch.
- [ ] describe-composition: release and `version.txt` read at the composition boundary, session
  opened for reading, selection, leaf reads over the named keys, pending requests through the
  `inspect` renderer, success prints the page, refusal prints the usual receipt.
- [ ] describe-controls: foreign blueprint refused; missing and malformed `version.txt` refused;
  no file appears under a state directory.

## Slice 4: two-actor journey

- [ ] staged-release: the journey stages the blueprint and `version.txt` as the archive lays them.
- [ ] page-readings: each actor describes before booking, after their own fold, in text and in
  JSON, twice, and the receipts are kept.
- [ ] page-rows-computed: the two page rows are computed from those receipts against `inspect`
  and the fold receipts; removing one receipt turns its row pending; the exit status no longer
  excuses them.
- [ ] home-unchanged: the actor's home tree is the same before and after a page.
- [ ] harness-controls: the status test and both control wrappers cover the new rows.

## Slice 5: help and docs

- [ ] help-and-flags: usage text and the flags page agree, and the flags check refuses a planted
  disagreement.
- [ ] registry-page-docs: a page with the story, a diagram, a sample page generated by the tool
  from the journey, the refusals and the limits; the onboarding page says what is delivered and
  what is not; navigation entry.
- [ ] narration-regenerated: speech companions from the extraction tool, stale clips regenerated
  with the authorized key, unchanged clips reused, `docs/audio/` committed alone.

## Slice 6: archive version

- [ ] archive-stages-version: `version.txt` beside the archive's blueprint.
- [ ] release-check-refuses-disagreement: missing, other or unchecksummed version refused by name.

## Close

- [ ] final-local-gate: lint, format, focused suites, flags, docs, then `just ci` once.
- [ ] pull-request-record: the template filled with the model revision, maps, evidence and limits.
