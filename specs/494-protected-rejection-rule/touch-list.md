# Touch list: every file the coding slices may touch

This page lists each file or group of files the four slices change, whether it is written by hand
or regenerated, which shared surface it belongs to, and which other lane owns that surface and in
which order. A coder who needs a file not listed here, or finds another lane's change in a listed
one, stops and asks the ticket owner before continuing (merge queue rule five). The base is
`e3c9ab01`. Slice numbers follow the [plan](plan.md).

## Story

As the desk granting merge slots, I read which surfaces this ticket shares with which lanes, so
that I can order it behind the lanes it would collide with and tell every lane which of its files
this ticket regenerates.
